# Windows 本地启动

## 运行前提

- 安装 Node.js 18+ 和 Python 3.11+；缺少 Python 时可按后端脚本提示安装。
- MySQL 8.0+ 和 Redis 已启动，并且 Windows 可以连接。
- 提前创建 MySQL 空数据库（默认 `xianyu_data`），数据表由后端启动时自动初始化，无需导入 SQL。
- 首次启动需要联网下载依赖和 Chromium，等待脚本执行完成即可。

## 连接配置

三个后端服务分别读取以下文件，MySQL 和 Redis 连接信息需要保持一致：

```text
backend-web/.env
websocket/.env
scheduler/.env
```

缺少 `.env` 时，后端脚本会提示输入连接信息并生成配置；已有配置不会被覆盖。数据库名以 `MYSQL_DATABASE` 为准。

## 启动步骤

在项目根目录依次操作：

1. 双击 `启动后端.bat`，等待三个后端服务全部启动成功。
2. 双击 `启动前端.bat`，等待前端启动成功。
3. 浏览器打开 http://127.0.0.1:19000 。

首次初始化后的默认账号为 `admin`，密码为 `admin123`，登录后请修改密码；已有管理员账号不会被重置。

## 停止与重启

- 使用期间保持两个启动窗口打开；分别在窗口按 `Ctrl+C` 停止对应服务。
- 修改后端 Python 代码或 `.env` 后，需要停止并重新运行 `启动后端.bat`。
- 不要重复启动同一服务，避免端口被占用。
